# Changelog

## v1.1.0

Added analytical AMD FSR 3.1.5 Native AA and Super Resolution, with native-device capability checks, SDK-selected resolution/jitter, automatic reactive masks and optional sharpening. Unity remains on D3D11; FSR uses a synchronized same-adapter D3D12 bridge. DLSS model selection and original AA fallback are preserved. Frame generation is not included in this version.

Fixed repeated warnings when checking camera components that have no image-effect method.

## v1.0.1

Fixed a field-access error that broke the graphics settings menu.
